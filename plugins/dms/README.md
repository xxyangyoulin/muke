# 桌面更新日志

读取 DMS 插件清单、运行内核版本和 Arch 软件包数据库，通过统一任务队列记录安装与版本变化。

后台填写 DMS 配置目录（如 `~/.config/DankMaterialShell` 对应的绝对路径），需有可读的 `plugins/` 子目录。启用后默认每分钟检查，也可手动同步。首次同步或更换目录只建立基线。

插件版本以清单为准；内核以实际运行版本为准；DMS 软件包从 `/var/lib/pacman/local` 读取。两次检查之间已安装又卸载的插件无法检测。基线在动态成功入库后推进。

建议在桌面所在机器运行。容器需只读挂载 DMS 配置目录、符号链接目标及可选的 Arch 软件包目录。内核信息来自服务运行环境，远程服务器不能代表本地桌面。
